## 📖 О книге

Практическое руководство по современному веб-фреймворку FastAPI. Книга охватывает все аспекты разработки: от создания простых API до сложных многоуровневых приложений с базами данных, аутентификацией, визуализацией данных и деплоем.

**Ключевые темы:**
- ⚡ Асинхронность и конкурентность (Starlette, ASGI)
- 🛡️ Валидация данных через Pydantic
- 🏗️ Многоуровневая архитектура (Web → Service → Data)
- 🔐 Аутентификация и авторизация (OAuth2, JWT)
- 🗄️ Работа с базами данных (SQLite, SQLAlchemy)
- 📊 Визуализация данных (Plotly)
- 🐳 Деплой (Docker, Gunicorn, HTTPS)
